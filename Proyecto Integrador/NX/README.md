# Siemens NX Mechatronics Concept Designer (MCD)

Esta carpeta contiene el desarrollo del **Gemelo Digital (Digital Twin)** del proyecto integrador utilizando **Siemens NX Mechatronics Concept Designer (MCD)**. En este entorno se modeló y simuló el comportamiento de la línea automatizada de empaque, permitiendo validar el funcionamiento de los mecanismos, sensores, actuadores y secuencias de control antes de su implementación.

El Gemelo Digital constituye uno de los componentes principales del proyecto, ya que integra el modelo mecánico con la lógica de control y las simulaciones, facilitando el análisis del proceso y la validación de la solución de automatización.

## Objetivo

El desarrollo del Gemelo Digital permitió:

* Modelar la línea automatizada de empaque en un entorno virtual.
* Validar el comportamiento mecánico de la planta.
* Integrar sensores, actuadores y mecanismos de transporte.
* Simular la secuencia completa de operación del sistema.
* Verificar la interacción entre los diferentes componentes antes de su implementación.
* Servir como base para la integración con la lógica de control, ABB RobotStudio y el sistema de supervisión.

El uso de **Siemens NX Mechatronics Concept Designer** permitió reducir riesgos durante el diseño, facilitar la validación del proyecto y aplicar conceptos de **Digital Factory** e **Industria 4.0**, integrando el mundo físico y digital mediante un Gemelo Digital del proceso de manufactura.
