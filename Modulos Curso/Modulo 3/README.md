# Módulo 3 - Planeación de Proyectos

Este módulo presenta las herramientas y metodologías necesarias para planificar, estructurar y evaluar proyectos de automatización. Se abordan conceptos fundamentales de gestión de proyectos, la metodología **EDT (Estructura de Desglose del Trabajo)**, indicadores de gestión y modelos de negocio, los cuales sirven como base para la organización y desarrollo del proyecto integrador del curso.

## Objetivos

* Comprender los conceptos fundamentales de la gestión de proyectos.
* Aplicar la metodología **EDT** para estructurar un proyecto.
* Analizar indicadores de gestión para el seguimiento del proyecto.
* Evaluar propuestas mediante herramientas de análisis y modelos de negocio.
